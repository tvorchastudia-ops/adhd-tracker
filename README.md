# 🔥 Звички — трекер звичок для телефону

Яскрава апка-трекер: серії днів, статистика з календарем, звички по днях тижня, нагадування, конфеті та нагороди. Працює офлайн, встановлюється на головний екран як звичайний застосунок.

## Як викласти на GitHub (≈5 хвилин, без програм)

1. Зайди на [github.com](https://github.com) і увійди в акаунт (або зареєструйся).
2. Праворуч угорі **+** → **New repository**.
   - Назва: `zvychky` (будь-яка, латиницею).
   - Обери **Public** → **Create repository**.
3. На сторінці нового репозиторію натисни посилання **uploading an existing file**.
4. Перетягни **всі файли з цієї папки** (`index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`, `README.md`) → внизу **Commit changes**.
5. Відкрий **Settings** → зліва **Pages**.
   - **Source**: *Deploy from a branch*.
   - **Branch**: `main`, папка `/ (root)` → **Save**.
6. Зачекай 1–2 хвилини й онови сторінку — зʼявиться адреса на кшталт
   `https://твій-логін.github.io/zvychky/`

## Як встановити на телефон

**iPhone (Safari):** відкрий адресу → кнопка **Поділитися** (квадрат зі стрілкою) → **На початковий екран** → **Додати**.

**Android (Chrome):** відкрий адресу → меню **⋮** → **Встановити застосунок** / **Додати на головний екран**.

Після цього апка відкривається з іконки на весь екран і працює без інтернету.

## Нагадування — важливо знати

- Увімкни в апці: ⚙️ → **Нагадування** → **Увімкнути** і дозволь сповіщення.
- На **iPhone** сповіщення працюють лише в апці, встановленій на головний екран (iOS 16.4+).
- Апка без сервера, тому нагадування приходять, коли вона відкрита або нещодавно згорнута. Якщо телефон повністю закрив апку — нагадування прийде, щойно ти її відкриєш (протягом 3 годин після обраного часу). Для «залізних» нагадувань додатково постав будильник.

## Дані

- Усе зберігається **лише на твоєму телефоні** (нічого не відправляється в інтернет).
- ⚙️ → **Експорт** — зберегти резервну копію; **Імпорт** — відновити на новому телефоні.
- Якщо очистити дані браузера/Safari, прогрес зникне — роби експорт час від часу.

## Як оновити апку

Заміни потрібний файл у репозиторії (**Add file → Upload files**). Телефон підтягне нову версію при наступному відкритті з інтернетом.
